# scripts/

Operational tools (run these), plus the handful of libraries they import — a file
here with no `main` is one of those, named in its driver's entry below. Most Python
ones are `--help`-documented; the seven
older acquisition/build scripts (`fetch_new_goldens.py`, `fetch_special_sheets.py`,
`freeze_new_goldens.py`, `make_fixture_manifest.py`, `make_loop_renumbering_table.py`,
`serve_viewer.py`, `validate_new_goldens.py`) take no flags and carry their usage in
a header docstring — running one with `--help` RUNS IT. The shell one carries its
usage in a header comment.

Three subdirectories hold a family whose members only make sense together, and a
new file joins one only when it belongs to that family: `lint/` is the gates
`make lint` runs, `walkthrough/` is the illustrated-walkthrough generator and the
libraries only it imports, and `experiments/` is a harness whose only caller is
another harness. Everything else sits flat here, beside the tool that drives it.
A family lives in one directory because its members import each other by bare
name off `sys.path`, which resolves against the importing file's OWN directory —
so a driver and its libraries move together or not at all. That same rule is why
such a family needs NO `mypy_path` entry: mypy searches a file's own directory
too. Only a bare-name import reaching ACROSS directories needs one, which is
what `scripts/experiments` is on that list for.

Anything under `scripts/` that reaches a model backend says so on one line of its
module docstring, starting `SPENDS BUDGET:` and naming the unit billed, so
`grep -rn '^SPENDS BUDGET:' scripts/` is the whole list before you run one.
Two files carry it: `annotate_volume.py` and `validate_new_goldens.py`.
Everything else is free.

- `lint/check_docstrings.py` — the docstring and comment budget, run by `make lint`. Bounds docstring and comment-block length and bans planning-doc citations, dates, roadmap numbers, volume ids, and city lore from prose; nothing upstream does either. The gating trees are at ZERO, so any violation fails the build; `# noqa: DSNNN` is the deliberate, reviewable exception (`pyproject.toml` declares `DS` in `lint.external` so ruff accepts it). `make docstrings` reports every site including `experiments/`, which is scanned but never gates. `tests/test_check_docstrings.py` loads it by path.
- `lint/check_module_size.py` — the module-size budget, run by `make lint`. Ruff has no module-length rule and pylint's `C0302` was never ported, so nothing else stops a file that grows by accumulating small functions. It counts CODE lines — blanks, whole-line comments and docstrings excluded, because a raw-LOC cap would tax the documentation every module is asked to carry — and public names, which for a package `__init__` means what it RE-EXPORTS, so the facade convention has a number behind it. It gates on a ratchet, not a bar: `module_size_baseline.json` records today's figure for each file already over a cap, and a file fails only when it grows past its own entry. A new file is judged against the flat cap. `--update` re-records the baseline and refuses to raise any number OR the total, which is what stops a rename laundering growth past a per-path check; the tests pin every recorded number to the current measurement, so hand-editing one up fails too. `experiments/` is measured but never gates, and `tests/test_check_module_size.py` runs the gate over a throwaway tree so it is seen to fail, not only to pass. `make module-sizes` reports every file with its headroom.
- `lint/check_symbol_reachability.py` — the symbol-level companion to the module contract below, run by `make lint`. Reports every module-level `def`/`class` in the package that nothing under `src/` or `scripts/` imports, not counting `tests/` as a consumer. That is a weaker question than the module contract's (which is transitive reachability from `autogeoref.cli.entry`), asked of a finer unit, and it sees two things the contract cannot: a symbol whose only importer is its own test, and a `def`/`class` written inside a package `__init__` that the `__init__` does not re-export. A symbol the `__init__` DOES re-export stays live, because the `__init__` is scanned as a live consumer. Import edges are RESOLVED from an AST, never name-matched — `vulture`, `dead`, and `deadcode` all match names, which reports a dead symbol as live wherever a harness defines the same name locally or passes it as a keyword argument. It refuses to run over a star import rather than guessing; ruff's `F403` keeps one out of the tree. Gates on a frozen count like the ruff ceilings and the docstring budget; `--report` lists every finding and says whether deleting one also breaks a test. `tests/test_check_symbol_reachability.py` loads it by path. Its AST import resolver is deliberately separate from the one in `tests/test_script_imports.py`: that one asks whether a script's imports still resolve at RUNTIME and reports line numbers, this one builds a static edge set, and folding them together would make the script-import gate depend on a lint script and lose its citations.
- `lint/import_contracts.py` — custom `import-linter` contract types, run by `make lint` through `lint-imports` (which gets this directory on `PYTHONPATH`). `ReachableFrom` asserts every non-package module is imported, directly or transitively, from `autogeoref.cli.entry` (the console script, not the `cli` package — grimp reports nothing upstream of a package module); a module that is not must be named in the `allow` list in `.importlinter`, which makes "deliberately outside the product" a written, reviewable claim instead of a docstring nothing reads. It also fails on an `allow` entry that has become reachable, or that names no module. `MaxFanOut` caps how many package modules one module may import — the direct measure of a god module, and the one ceiling that catches a file grown by accumulating small functions. It takes the same `allow` list with the same three failure modes, so an entry recording a planned split fails once the split lands. `tests/test_import_contracts.py` loads it by path; `tests/test_lint_budgets.py` pins the cap and the ruff ceilings beside it, and runs ruff over source it hands it so a rule switched off by `ignore` cannot pass as configured.
- `make_fixture_manifest.py` — regenerate `FIXTURE-SHA256SUMS` after a legitimate fixture addition.
- `walkthrough/make_walkthrough_assets.py` — render the illustrated pipeline walkthrough (`docs/HOW-IT-WORKS.md`, and `viewer/walkthrough.html` beside the map viewer) from one placed volume. Zero model spend, zero network, Pillow only. Its INPUT is a gitignored `work/` tree and its OUTPUT is tracked, the same shape as `FIXTURE-SHA256SUMS` and for the same reason: a cold clone cannot run it, so what it produced is committed — do not "fix" that by gitignoring the output. It calls the pipeline's own functions rather than restating them, and refuses to draw a page whose recomputed candidate and inlier counts disagree with the record on disk; each gate counterexample it prepares is measured for the defect it claims rather than trusted, because the three spread checks share one refusal name. The `walkthrough_*.py` files beside it are its libraries, imported by bare name off `sys.path` the way `renumber_transcribe.py` is, and `walkthrough_exemplars.json` pins which volume and which sheets it uses. `tests/test_walkthrough.py` checks the committed assets against the package's own constants; `tests/test_walkthrough_browser.py` loads the page and steps through every panel, which is the only tier that can see a plate that does not resolve.
- `fetch_new_goldens.py` / `freeze_new_goldens.py` / `validate_new_goldens.py` — golden-testbed expansion: download, freeze, and validate new reference volumes. `validate_new_goldens.py` SPENDS BUDGET: one model call per uncached small in its `annotate` step.
- `fetch_loc_volume.py` — THE acquisition: download every page of one or more LOC volumes into `work/<vid>/jp2` (masters) and `work/<vid>/regions` (the pipeline's inputs). Usable on its own, and what the queue's `fetch` track shells out to, so there is one polite LOC lane. `--dry-run` prices the pacing floor; rerun to retry failed pages.
- `fetch_special_sheets.py` — download the digitized special single-sheet items (`_013`, `_016`, `_188`, `_189`, `_190`) into the per-volume `work/<vid>/regions` layout; rerun to retry failed segments. Predates `fetch_loc_volume.py` and differs deliberately: those five store the jp2 in `regions/` as the only copy, so `fetch_loc_volume.py` leaves their pages alone rather than deriving a second file per sheet.
- `fetch_osm_centerlines.py` — pre-fetch the OSM centerline cache for a city config.
- `fetch_osm_rail.py` — one polite Overpass fetch of a city's railway geometry (the `rail.RailIndex` input; the channel only produces candidates for labels bound in `configs/<city>/rail-gazetteer-<city>.json`).
- `fetch_osm_waterways.py` — one cached named linear-waterway extract for a bounded experiment (lake and shoreline polygons excluded); refuses to overwrite the stored raw response so later calibration replays the same reference. `tests/test_fetch_osm_waterways.py` loads it by path.
- `infer_aliases.py` — bootstrap street-name alias files for a new volume.
- `annotate_volume.py` — batch v2 annotation of one volume's sheets (cached, resumable, `--jobs N`, `--dry-run`). SPENDS BUDGET: one model call per uncached page.
- `serve_viewer.py` — local static server for the tile viewer.
- `wheel_smoke.py` — build the wheel and prove the declared distribution contract (metadata, console script, packaged UI resources) from a fresh install; CI's `package` job runs it via `make package-smoke`.
- `bake_volume_pmtiles.py` — bake one volume mosaic into an alpha-correct WEBP PMTiles archive (the serving-side re-bake tool).
- `run_bake_queue.sh` — run `bake_volume_pmtiles.py` over a list file in N parallel lanes under `nice`, regenerating the viewer manifest after each landing.
- `migrate_rescue_record_corners.py` — one-off migration: append the pinned rescue model's corner GCPs to committed rescue records that predate `rescue.with_synthetic_corners`, which `stage_rescue` walks past because it only processes `REJECTED` pages. `tests/test_migrate_rescue_corners.py` loads it by path.
- `reseam_volume.py` — re-run the seam solve over a volume's committed records, in place. The re-bake's first step and the one a bare `--warp-only` bake does not cover: rewriting `gcps_geojson` moves the per-sheet fit that seam ties are measured against, so the joint solve must re-run before the warp. Idempotent — a repeat run applies zero.
- `transcribe_renumbering.py` — OCR transcription of Chicago's published renumbering books (city-specific data production). Local OCR plus the PDF text layer; it makes NO model calls despite the name. Its two libraries sit beside it rather than in the package, because no pipeline stage imports either: `renumber_transcribe.py` is the parsing core (a row is accepted only when two independent reads agree) and `renumber_chains.py` stitches accepted rows into chains, validates them, and compresses to block ranges. They are imported by bare name, which works because Python puts a script's OWN directory on `sys.path` — the working directory is irrelevant, and `python -P` breaks it. `tests/test_renumber_transcribe.py` reproduces that with `conftest.load_script`. The AST scan below cannot see a bare-name edge, so `mypy_path` in `pyproject.toml` is the only thing that fails when one of these moves; do not replace it with a blanket `ignore_missing_imports`.
- `make_loop_renumbering_table.py` — city-specific data production: merge the 1909 and 1911 renumbering books into `configs/chicago/renumbering-chicago-loop-merged.json`, subtracting every old number both books claim. Its output is committed; `tests/test_renumbering_table.py` asserts the committed file still matches what this produces.

Recurring read-only instruments. Every one is ZERO model spend and ZERO network, and none changes a placement; some write renders or a sample file where you point them. Where each one looks is NOT uniform: two read `AUTOGEOREF_WORK` / `AUTOGEOREF_DATA_ROOT`, most take a `--work` flag defaulting to `work` relative to the CURRENT DIRECTORY rather than to the checkout (`replay_and_validate.py` is the exception — its defaults are checkout-rooted), and `measure_disjoint_flipset.py` is hardwired to the checkout's own `fixtures/` with no way to repoint it. Run them from the repo root, and on a worktree check where the tool actually looked before trusting a zero.

- `audit_alias_coverage.py` — the corpus-wide alias-gap sweep: per volume, the share of annotated street reads whose normalized key is in the volume-bounded index, and the share of results with no candidates. Rebuilds the index the way `autogeoref run` does, so an existing alias file is applied and a flagged volume is a real gap. Its two bars and its counting are imported from `autogeoref.name_match`, NOT re-spelled — `tests/test_name_match.py` asserts they are the same objects, which is what keeps a sweep number and a run number comparable. Unlike the per-run report note it floors nothing on sample size, so tiny special items get flagged too.
- `validate_alias_files.py` — re-validate every alias file on disk against its volume's ALIAS-FREE bounded index. Discovers every `aliases-*.json` in the city's alias directory, so a new table is checked the day it lands; the structural rules come from `autogeoref.alias.validate`, and the `CONTRACT` list adds end-to-end normalizer cases (reads it MUST catch, reads it must NOT catch). Traps: a volume with no declared and no persisted bounds is REPORTED AND SKIPPED, not failed, so a green run on a thin checkout proves less than it looks; and a `PRE_EXISTING` excuse that no longer fires is a failure, because a stale excuse would silently cover a different violation later. `tests/test_validate_alias_files.py` loads it by path.
- `escalation_spend_probe.py` — size a re-place before approving it: per volume, the model calls `stage_escalate` would spend. `autogeoref run --dry-run` cannot answer this (it plans the annotate stage only), so use this instead of a ceiling. Prints two figures — ELIGIBLE NOW (the expected bill) and WORST CASE (status filter dropped, because a re-place can demote an accepted page, which has no escalation cache). Reuses the stage's own helpers where it can, so those cannot drift without the import breaking; the cache filenames and the status filter are re-spelled here and CAN drift silently. A failure marker counts as a cache hit, not a call. `tests/test_escalation_spend_probe.py` loads it by path.
- `audit_fixture_volume_identity.py` — does `fixtures/<vid>/` actually hold volume `<vid>`? Hashes each fixture `sheets/p<N>_small.jpg` against its `work/` counterpart and reports MISFILED below `MATCH_FLOOR`, naming the volume the tree really holds. Falls back to comparing annotation street-name sets where the smalls are absent — weaker, still decisive. A fixture tree with no `work/` counterpart is "not checkable here", which is not a pass. `tests/test_audit_fixture_volume_identity.py` loads it by path.
- `audit_reflected_placements.py` — find committed sheets whose placement model MIRRORS the scan (positive determinant on the 2x2 linear part). Nothing in the accept path tests handedness, so such a sheet reaches the mosaic as a normal accept and paints opaque black corners. Read-only over `results/`. `tests/test_rescue.py` loads it by path and runs it over the fixture corpus as a contract, so its rule is the one the suite defends.
- `audit_score_extent.py` — say when a pin score is not a displacement. The grader fits an affine to each side and reports metres; where the two sides imply a different sheet SIZE, those metres fold a scale disagreement and the number means nothing. This walks both affines over the sheet's `full_size`, in true ground metres, and reports the ratio per page, the off-band pages with their counts, and the tail figures with and without them — plus a band sweep, so the band reads as the choice it is. It also names the SUSPECT side, by comparing each side's implied metres-per-pixel to its own volume's median; that is a pointer, not a verdict, and it inverts on a sheet whose printed map scale differs from its volume's. `--corpus` enumerates from the city configs and prints the set first (neither glob reaches both cities). Its joining and its pin loading are the score pass's own functions rather than a re-spelling, so a page it counts is a page a published figure counted; the accept-status filter is the one line it does re-spell, and a page the grader scores and this cannot measure is printed by name rather than dropped. `score_extent.py` beside it is the measurement library it drives, imported by bare name the way the renumbering pair are; `tests/test_score_extent.py` loads both by path and pins the ratio against injected scales, the interval against a one-volume effect, and the config attribution against three cities sharing a work root.
- `measure_disjoint_flipset.py` — reproduce the raw-label vs normalized-label rescue-disjoint measurement over the fixture corpus, computing the retired raw rule inline. Exits 1 if any recorded revocation would regress, which must stay at zero.
- `replay_and_validate.py` — `replay` re-runs the production matcher over every cached read of a volume's flagged pages, to find placements the pipeline could hold but does not; `validate` builds an evidence dossier per candidate page (margin adjacency, corroboration, addresses vote, junction verdict) and renders a ghost composite. Read-only in both modes: `validate` renders from a scratch copy so the source tree is never written. Traps: `replay` runs against TODAY's index, so it prints alias/index drift separately from genuine second-read wins — only the latter is evidence a re-read was needed; and `--margins` numbers must be read off the scan, where a division suffix (`70w`) is a different division's page, not this volume's. `tests/test_replay_and_validate.py` loads it by path.
- `water_incidence_survey.py` — freeze and report the stratified waterway-incidence sample (`water_incidence_sample.json`, kept beside the script). `freeze` refuses to overwrite an existing sample and draws reproducibly from a fixed seed; `report` fails on any unreviewed row and on an "eligible" row lacking named non-lake water and a crossing street. `tests/test_water_incidence_survey.py` loads it by path.
- `water_overlay_calibrate.py` — project a named modern waterway crossing through a committed sheet affine and compare it to the manually reviewed label axis on the scan; `--render-dir` draws the overlay. Alters no placement. `summary()` applies the calibration bar (median and max offset BOTH), and `tests/test_water_overlay_calibrate.py` loads it by path to pin that both limits bind. Default testbeds are `water_calibration_testbeds.json` beside the script; other reviewed sets pass through `--testbeds`.

`experiments/` holds the shared libraries a measurement harness would import:
`water.py`, `qualification.py` and `numeral_rules.py`. They live here rather
than in the package because no pipeline stage imports any of them, which is
what the directory is for. `water_overlay_calibrate.py` reaches down for
`water.py` by name; `qualification.py` scores a candidate annotation backend
against cached fixtures, which is the qualifying step a new backend must pass
before it is trusted. `tests/test_water.py`, `tests/test_annotator.py` and
`tests/test_numeral_rules.py` load them by path.

Two gates keep an API change from silently orphaning a script, because nothing
runs one: `make typecheck` runs ONE strict mypy pass over the package and the
script tree (`pyproject.toml`), and `tests/test_script_imports.py` parses every
file and resolves each `autogeoref` symbol it imports without executing
anything. Only mypy sees signature drift — a parameter added or removed, a
parameter or return whose TYPE changed — which is why both exist. A script is
held to the same bar as the package, so moving code out of `src/` no longer
costs its typing. One constraint comes with the single pass: neither this
directory nor `tests/` has an `__init__.py`, so mypy names a file by its bare
stem and one here can no longer share a stem with one under `tests/`. The
collision is loud (`Duplicate module named ...`), not silent.

`tests/test_conduct.py` scans every `.py` under `scripts/` for model conduct and
asserts `experiments/` is non-empty; `make docstrings` reports both tiers and
neither gates. A file here may import a sibling by name off `sys.path` — **do
not move or delete one without checking**.
