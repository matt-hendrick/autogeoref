This page RUNS the pipeline. Every number on it is read off the work tree when you load it, and every button is the same call the CLI makes — autogeoref queue still does everything it does today. Queueing a volume spends model budget (~1 call/sheet): the estimate is on the button.

This console is READ-ONLY — it was started without --city.
Every action below is greyed out because a run needs a city config (and so does the ghost-overlay review, and the address-era check that decides what is even runnable). Stop this server (ctrl-c) and restart it to ACT:
autogeoref queue --serve --city <your-city.toml> --work <work>
Then Start drain, Queue, and Review light up. Everything else on the page — the board, the backlog, the estimates — is live either way.

Stopping kills the drain and the run under it. Model reads already paid for are cached and replay free, so a stopped volume does not burn its spend again — but a stage killed mid-write can leave a partial output, and the stopped volume is marked failed so you can clear or retry it.
